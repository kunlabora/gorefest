# Accessibility

Prefix: `A11Y`

What every page promises to someone using a screen reader, the keyboard, a zoomed screen or another theme (WCAG 2.2 AA's
basics). Most are kept by construction: the components in `web.components` render them, and `ArchitectureTest` keeps
views from going around the components. The design is in `docs/requests/a-accessible-by-construction.md`.

## Forms

- **A11Y-1** Every form control has a label tied to it, so a screen reader names it.
- **A11Y-2** A field's hint and error are read with its control, and a refused field is marked invalid.
- **A11Y-3** A set of choices (segmented control, chips, switches, a list of dates) is announced with its question.

## Names

- **A11Y-4** Every button and link has a name a screen reader can say, icon-only ones included, and one of several alike says what it acts on.
- **A11Y-5** Decorative icons and pictures are hidden from screen readers; an image that informs says what it shows.
- **A11Y-6** A toggle says whether it is on.

## Structure

- **A11Y-7** Every page names its language and has one main heading, one main region and named navigation.
- **A11Y-8** Headings follow each other without skipping a level.
- **A11Y-9** Ids on a page are unique, and every reference to one (labels, descriptions, controls, htmx targets) resolves.
- **A11Y-10** When htmx swaps something in, a screen reader hears what changed; a refusal is announced at once, and a background refresh stays quiet.
