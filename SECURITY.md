# Security

Boardfest holds people's email addresses and the game days they join, so security problems matter even though it's a small app.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through GitHub instead: the **Security** tab of this repository → **Report a vulnerability**. You'll hear back within a week.

Useful to include: what an attacker can do, the steps to reproduce it, and the version (shown in the page footer, or `version` in `build.gradle.kts`).

## Scope

The code in this repository, and the instance the maintainer runs. Instances other people run are theirs to look after.

Please test against a local copy (`README.md` → "Run it locally"), not someone's live instance. Dev mode needs no accounts or tokens.
